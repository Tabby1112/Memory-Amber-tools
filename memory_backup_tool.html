使用須知

目前僅支援電腦版 Chrome / Edge，不支援 Safari、Firefox 或手機瀏覽器。

Memory Amber 本身不會把你的資料傳到我們的伺服器——所有讀寫都只發生在你自己選擇的本機資料夾。（使用「呼叫 AI 整理」功能時例外，詳見下方說明）

下載時請確認網址來源「https://tabby1112.github.io/Memory-Amber-tools/memory_XXXXXXX_tool.html」，不要在來路不明的網站下載連結，守護好自己的電腦跟API金鑰。

控制台會以獨立彈出視窗顯示，不會遮住記憶體頁面內容。如果瀏覽器擋下彈出視窗，請允許此網站的彈出視窗後再點一次書籤。

使用小工具內的「呼叫 AI 整理」時，會把你選擇整理的當天對話，傳送到你自己填入金鑰的那個 AI 服務商(Anthropic / OpenAI / Google)，請先了解該服務商的資料保留政策，尤其內容偏私密的話。

若勾選「記住金鑰」，金鑰只會存在你目前使用的這台電腦/瀏覽器裡；若是公用電腦或共用裝置，建議不要勾選。

安裝方式
1

顯示書籤列

如果瀏覽器上方沒有看到書籤列，先按 Ctrl/Cmd + Shift + B 顯示它。

2

拖曳琥珀到書籤列

用滑鼠按住上方那顆羽毛琥珀，拖到書籤列上放開，就會變成一個書籤按鈕。如果拖曳沒有反應，也可以右鍵複製連結網址，手動新增書籤貼上。

3

打開卿卿我我網頁

登入你的帳號，進入你想備份的角色對話窗，打開右邊記憶體。

4

點一下書籤

點擊剛剛加入的書籤，會跳出一個獨立的控制台視窗。選擇（或建立）記憶資料夾、填寫結束日期後，按「開始擷取並存入資料夾」，工具會自動幫你捲動頁面、依日期封存記憶。如果只是想確認目前能捲到多早的日期、還不想存檔，可以改按旁邊的「僅尋找日期不存入資料夾」，這個按鈕不需要先選擇資料夾，也不會寫入任何檔案，只會捲動並回報偵測到的最早日期。

5

比對與覆寫

用「對話拆解工具 」整理好至少一天的內容後，回到這個控制台，按「掃描Memory Amber並比對」，確認差異無誤後，可以先「測試寫入第一筆」，確認無誤再「開始批次覆寫」。
